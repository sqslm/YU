# 语 YU · Logo 与 Windows 图标套件

该套件依据你选中的「深海军蓝门框 / 白色门板 / 蓝色入口」版本重新绘制为可缩放矢量几何。避免此前将包含“语 YU”文字和白色背景的整张图片直接缩成任务栏或贴在深色侧边栏的错误。

## 使用建议

- **应用内深色主题（例如左侧导航栏）**：使用 `01_应用内Logo/YU_侧边栏紧凑版_深色界面.png` 或相应 SVG。它是透明背景，不存在突兀的白色矩形。
- **应用内浅色主题**：使用 `01_应用内Logo/YU_侧边栏紧凑版_浅色界面.png`；关于页面、官网可使用横版 / 竖版。
- **Windows 主程序、快捷方式、任务栏**：使用 `02_应用图标与任务栏/YU_Windows主图标.ico`，它包含 16/20/24/32/48/64/128/256 等各自优化的尺寸。任务栏不要用完整的“语 YU”品牌图。
- **系统托盘**：深色托盘选 `03_托盘图标/YU_托盘_暗色托盘_白色线条.ico`；亮色托盘选 `YU_托盘_亮色托盘_深色线条.ico`。如可监听 Windows 主题变更，请跟随切换；否则选择在默认托盘色下对比度高的版本。
- **托盘只有 16-20px 时**：使用 `YU_托盘_*_16.png`、`*_20.png`；纯线条、没有中文字、没有背景底板。Windows 高 DPI 根据实际图标规模取 20/24/32。
- **可复用纯符号**：应用内小标题、悬浮入口可以使用 `YU_纯符号透明_浅色界面.svg` / `_深色界面.svg`，不要使用完整大字标压缩。

## 特别注意

1. 深色页面不要直接使用“白底应用图标”；应用内 Logo 用透明背景的深色主题变体。
2. 不要拿大号品牌图等比例缩成 16×16；使用提供的专用任务栏或托盘小图。
3. 主程序 `.ico` 是多尺寸资源；不要使用单张大 PNG 伪装 ICO。
4. 不要重新从图片里抠白色背景；已提供真正透明 PNG 和可缩放 SVG。
5. 所有 SVG 文字已转轮廓路径，不依赖用户电脑安装中文字体。
6. 只作为绘制源和品牌规范交付。若在应用中需要根据主题切换，沿用现有资源与主题机制，最小必要修改。

> 资源内不包含字体文件。最终定稿前建议在 Windows 100%、125%、150% 缩放，以及浅色/暗色任务栏中实际预览 16×16 托盘和应用图标。
